# AGENTS.md — 天文地理古籍库导航

> **这份文件是什么**：天文历法·自然地理一脉古籍库的**导航索引**，供 Agent 按需定位原文。
> **怎么用**：本文件只给"哪本书、在哪里、讲什么"。本域**无子目录**，两篇均为单文件，直接打开即可。
> **上级**：`../AGENTS.md`（古籍总库导航）

---

## 一、本域的定位（边界最窄）

**只服务干支历法、节气、分野与方位取象，不引入占星断事。**

| 用途 | 说明 |
|---|---|
| **历法溯源** | 干支从何而来、律历如何对应、年度如何起算 |
| **天文背景** | 星官体系、分野说（天区配地域）——理解"地支藏干""分野"等概念的背景 |
| **方位取象** | 天象与方位、方位的五行配属 |

> **硬约束**：**不引入占星断事**。星象变动**不用于**推断人事吉凶（与项目根 AGENTS.md 反对预测的立场一致）。本域只作历法与概念的背景材料。
