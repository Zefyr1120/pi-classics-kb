## 内容

### 素问王冰注本断句脚本（62 个：`suwen_punct_pian*.py`）

覆盖素问篇 1-71、74-81 的逐篇断句。每篇一个脚本，形态统一：

```python
PATH = r'...\古籍\内经\素问\99-王冰注本-存74篇.md'
REPL = {
    977: '　　脉要精微论篇第十七【新校正云：按全元起本在第六卷。】',
    978: '　　黄帝问曰：诊法何如？……',
    ...
}
```

**为什么是一篇一脚本**：
- 按**行号精确替换**，不碰其他行，杜绝误伤；
- 行号 + 内容双锚定，脚本本身就是**可复核的改动记录**；
- 每篇执行后即 `../suwen_verify_punct.py` 逐字校验 + git 提交，形成可追溯链。

**为什么归档**：内容是"素问断句"——**一次性的**。断句结果已固化进 `古籍/内经/素问/99-王冰注本-存74篇.md`，脚本再无执行价值。但它们是"改 5 万字零错字"这条方法论的实证，故留档。

### `suwen_punct_fix_variants.py`

断句过程中发现的异体字统一修正脚本，同属一次性产物。
