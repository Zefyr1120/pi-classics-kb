# AGENTS.md — 易学古籍库导航

> **这份文件是什么**：易学一脉古籍库的**导航索引**，供 Agent 按需定位原文。
> **怎么用**：本文件只给"哪本书、在哪里、讲什么"。需要内容时**再下钻到书的 `AGENTS.md` 或篇/卦文件**，不要停在这份索引。
> **上级**：`../AGENTS.md`（古籍总库导航）｜**下级**：`周易/AGENTS.md` 与各卦文件

---

## 一、本域的定位

易学域提供**义理层**材料，不用于占筮。

| 用途 | 说明 |
|---|---|
| **义理溯源** | "阴阳""变易""象数"等范畴的经典出处（项目根 AGENTS.md 命运观一节引《周易·系辞》"乐天知命，故不忧"即出此域） |
| **象义互参** | 八卦类象（乾天/坤地/震木/巽木/坎水/离火/艮土/兑金）——五行域"八卦各有其色"一段即引自易学体系 |
| **万物类象** | 十翼·说卦传是**类象的原始清单**，与子平域"干支类象"可对照 |

> **硬约束**：**不做占筮**。不用于起卦、断卦、做任何"会发生什么"的断言（与项目根 AGENTS.md 反对预测的立场一致）。本域只供义理与类象参照。

## 二、书单与内容索引

> 查找顺序：本表定位到书 → 进入书目录 → 读 `AGENTS.md` 定位到卦 → 打开卦文件。

| 书 | 存放 | 结构 | 讲什么 / 什么时候用 |
|---|---|---|---|
| **周易**<br>（经+十翼） | `周易/01-…64-…md`（64 卦）<br>`周易/十翼-*.md`（5 篇） | 64 卦逐卦拆分 + 十翼 5 篇。每卦含：卦辞 / 彖传 / 大象 / 爻辞与小象（表格）/ 文言传（仅乾坤） | **义理与类象的总源**。**查义理**（系辞、彖、象）→ 十翼；**查类象**（万物类象清单）→ 说卦传；**查某卦** → 按卦名打开。 |
| **易纬乾凿度**<br>（汉·郑玄注） | `易纬乾凿度.md`（单篇） | 卷上/卷下整篇 | **汉代易学宇宙论**。讲易之三义（易/变易/不易）、卦气、太易-太初-太始-太素生成序列。**溯源"汉人如何用易讲宇宙生成"时用**。⚠️ **含郑玄注层**，引用时分层（原文=经文，注=郑玄）。 |

### 周易卦文件结构

| 字段 | 内容 |
|---|---|
| 卦序/卦名 | 01—64，分上经/下经 |
| 卦象 | 上下卦（如 乾下乾上） |
| 卦辞 | 《X》：… |
| 彖传（彖曰） | 卦辞之解释 |
| 象传·大象 | 君子以… |
| 爻辞与小象 | 表格：爻位｜爻辞｜小象（象曰） |
| 文言传 | 仅乾、坤两卦 |

> 卦文件**分层表格化**，同一卦的经/传各层分列，便于按层引用。
