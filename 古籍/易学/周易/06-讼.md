# 讼（卦六）

> 卦序：06｜上经｜卦象：坎下乾上
> 底本：古籍/易学/周易-经传全文.md（原文）

## 卦辞

《讼》：有孚窒惕，中吉，终凶。利见大人。不利涉大川。

## 彖传（彖曰）

讼，上刚下险，险而健，讼。“讼有孚窒惕，中吉”，刚来而得中也。“终凶”，讼不可成也。“利见大人”，尚中正也。“不利涉大川”，入　　于渊也。

## 象传·大象

天与水违行，讼。君子以作事谋始。

## 爻辞与小象

| 爻位 | 爻辞 | 小象（象曰） |
| --- | --- | --- |
| 初六 | 不永所事，小有言，终吉。 | 讼不可长也。；其辩明也。 |
| 九二 | 不克讼，归而逋。其邑人三百户，无眚。 | 归逋窜也。自下讼上，患至掇也。 |
| 六三 | 食旧德，贞厉，终吉。或从王事，无成。 | 食旧德，从上吉也。 |
| 九四 | 不克讼，复既命渝。安贞吉。 | 复即命渝，安贞不失也。 |
| 九五 | 讼，元吉。 | “讼，元吉”以中正也。 |
| 上九 | 或锡之鞶带，终朝三褫之。 | 以讼受服，亦不足敬也。 |
