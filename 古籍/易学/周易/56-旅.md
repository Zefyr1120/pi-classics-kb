# 旅（卦五十六）

> 卦序：56｜下经｜卦象：艮下离上
> 底本：古籍/易学/周易-经传全文.md（原文）

## 卦辞

《旅》：小亨。旅贞吉。

## 彖传（彖曰）

“旅小亨”，柔得中乎外，而顺乎刚，止而丽乎明，是以“小亨旅贞吉”也。旅之时义大矣哉！

## 象传·大象

山上有火，旅。君子以明慎用刑而不留狱。

## 爻辞与小象

| 爻位 | 爻辞 | 小象（象曰） |
| --- | --- | --- |
| 初六 | 旅琐琐，斯其所取灾。 | 志穷灾也。 |
| 六二 | 旅即次，怀其资，得童仆，贞。 | 终无尤也。 |
| 九三 | 旅焚其次，丧其童仆，贞厉。 | 亦以伤矣。以旅与下，其义丧也。 |
| 九四 | 旅于处，得其资斧，我心不快。 | 未得位也。；心未快也。 |
| 六五 | 射雉，一矢亡，终以誉命。 | 上逮也。 |
| 上九 | 鸟焚其巢，旅人先笑后号咷。丧牛于易，凶。 | 终莫之闻也。 |
