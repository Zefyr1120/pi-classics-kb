# AGENTS.md — 古籍总库导航

> **这份文件是什么**：`古籍/` 目录的**顶层导航**，供 Agent 按需定位古籍原文与清洗工具。
> **怎么用**：这里只告诉"有哪些领域、各领域在哪个目录、该往哪下钻"。**不要指望从这里直接得到答案**——需要内容时下钻到该领域的 `AGENTS.md` / `README.md`，再下钻到书、到章。
> **上级**：`../AGENTS.md`（项目根基调与立场）

---

## 一、领域分布

| 领域 | 目录 | 讲什么 | 何时进入 |
|---|---|---|---|
| **子平（命理）** | `子平/AGENTS.md` | 子平类核心典籍——格局、用神、气势、调候 | 本项目语料主体 |
| 五行 | `五行/AGENTS.md` | 五行学说的早期系统论述（五行大义） | 需要五行的**本源义理**（不是命理应用）时 |
| 内经 | `内经/AGENTS.md` | 素问、灵枢等中医经典 | 研究"子平与中医理论基础同源"时（**当前项目口径：身体层不纳入**，见项目根 AGENTS.md 第三节） |
| 易学 | `易学/AGENTS.md` | 周易经传、易纬等 | 需要易学义理、卦象时 |
| 六壬 | `六壬/AGENTS.md` | 大六壬占法诸书 | 占法工具/纪律层研究（**不做性格子代理**） |
| 天文地理 | `天文地理/AGENTS.md` | 天文历法类古籍 | 溯源历法、干支天文背景时 |

> **首选**：涉及子平类概念的，进 `子平/`。
> **各领域均有 `AGENTS.md`**（子平、五行、六壬、内经、易学、天文地理 六域齐全）。进任一领域先读其 `AGENTS.md`，再下钻到书。

## 二、按需下钻路径

```
古籍/
├── AGENTS.md          ← 你在这里（顶层导航）
├── 子平/
│   ├── AGENTS.md      ← 子平领域导航（书单 + 决策表）
│   ├── README.md      ← 详细书单（含变更记录）
│   ├── 滴天髓/AGENTS.md、子平真诠/AGENTS.md …  ← 各书章索引
│   └── 01-章名.md …    ← 具体章文件
├── 五行/AGENTS.md      ← 五行领域导航
├── 六壬/AGENTS.md      ← 六壬领域导航
├── 内经/AGENTS.md      ← 内经领域导航
├── 易学/AGENTS.md      ← 易学领域导航
├── 天文地理/AGENTS.md  ← 天文地理领域导航（无子目录，单篇）
├── guwen-cleaning/    ← 清洗方法论（SKILL.md + references/）
└── tools/             ← 清洗脚本（README.md + 处理思路沉淀）
```

**层级职责**：
- **AGENTS.md**：导航与"讲什么"，供 Agent 判断该不该进、进哪里。分三级——本文件（总库）、**领域级（六个领域各有 `AGENTS.md`）**、书级（如 `子平/子平真诠/AGENTS.md`）。
- **README.md**：人工查阅用（详细书单、变更记录、示例）。
- **章文件**：真正的原文内容。

> 三级 AGENTS.md 会被 Pi **逐级加载并合并**，因此每级只写本级该管的事，不重复上级内容。
> ⚠️ **注意**：`天文地理/` 与 `五行/` 下有单篇文献（无子目录），其领域级 `AGENTS.md` 即终点，不再下钻。

## 三、分层纪律（全库通用，不可违反）

**原文 / 原注 / 注家三层严格分离，引用不得混引。**

已做的剥离（2026-09-10）：

| 书 | 保留 | 剥离 |
|---|---|---|
| 滴天髓 | 京图原文 + 刘基原注 | 任铁樵批注层 |
| 子平真诠 | 沈孝瞻原文 + 项目自撰【疏解】 | 徐乐吾评注、林君毅补注 |

**理由**：注家立场与项目口径存在已知冲突（任铁樵：阴阳同生同死 vs 项目采十干长生/火土同宫；徐乐吾：民国旺衰用神派 vs 沈孝瞻格局法），供 Agent 分析时须杜绝掺杂。详见 `子平/README.md`。
