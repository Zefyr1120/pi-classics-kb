# AGENTS.md — 六壬古籍库导航

> **这份文件是什么**：六壬一脉古籍库的**导航索引**，供 Agent 按需定位原文。
> **怎么用**：本文件只给"哪本书、在哪里、讲什么"。需要内容时**再下钻到书的 `AGENTS.md` 或章文件**，不要停在这份索引。
> **上级**：`../AGENTS.md`（古籍总库导航）｜**下级**：各书目录内的 `AGENTS.md` 与章文件

---

## 一、本域的定位（重要：本域不是占事工具）

**六壬在本项目是"方法论母体"，不是占测工具。**（口径见 `README.md`）

本项目从六壬域提取的是**分析纪律**，而非占断技法：

| 提取的方法论 | 含义 | 对八字性格分析的迁移 |
|---|---|---|
| **理气优先** | 先看气机结构，再看类象吉凶 | 先定气势流通，再谈十神含义 |
| **类神取象** | 以象归类，多象合取 | 干支象、宫位象合并解读 |
| **合取取象** | 单象不定论，多象印证 | 单一神煞不落判词，须格局/气势互证 |
| **生克第一** | 生克关系优先于象义吉凶 | 五行生克先于十神吉凶标签 |

> **硬约束**：本域**不做性格子代理**，不进入用户可见的分析输出。仅作为方法论纪律供内部参照。（口径同项目根 `../../AGENTS.md`）

## 三、按任务选书的决策表

| 我要做什么 | 读哪本 | 进哪个文件 |
|---|---|---|
| 学六壬怎么看（入门） | 六壬说约 | `六壬说约/AGENTS.md` → 卷上·入门 |
| 查理气框架（四课三传、生克先后） | 壬归 | `壬归/01-…05-…md` 前五节 |
| 查起课起例、神将 | 六壬大全 / 大六壬指南 | 六壬大全卷一、卷二；大六壬指南整篇 |
| 查歌赋、毕法赋 | 六壬大全 | `11-…毕法赋上.md`、`12-…毕法赋下.md` |
| 查课经集（具体课体） | 六壬大全 | `07-…10-…` 课经集一至四 |
| 查某日某局的古断 | 御定六壬直指 | 按日名打开，如 `01-甲子日.md` |
| 查占断总原则 | 大六壬指南 | 整篇（按行号检索，无章文件） |
