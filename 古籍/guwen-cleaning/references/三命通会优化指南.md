# 三命通会优化指南（专项）

> 目标书：古籍/子平/三命通会/（十二卷 389 章，明·万民英）——八字重要经典，结构需要格外打磨。
> 依据：古籍清洗核心规则（`格式规范.md` 〇节）；本文是该规则在三命通会上的专项实施方案。

## 一、目录与卷级结构（渐进式披露）

现状：`目录.md` 是旧式逐章清单（冗长且无信息量），卷文件头部无概览。

重构为三层：

### 1. 书级 `目录.md`

十二卷各一段"本卷讲了什么、有什么关键信息"（如卷七：六甲日各时断+子平说辩+性情相貌/疾病/贫贱凶恶/寿夭/女命等总论——即"日时断与断命总纲"），附卷文件链接。

格式：

```markdown
## 卷七 —— 古籍/子平/三命通会/卷七.md（XX 章）

本卷主题：日干×时断（六甲日甲子时…六戊日癸亥时）+ 子平说辩等命理总论。
关键信息：逐日断语是"日主×时柱"的实战索引；子平说辩讲子平法源流与正名。
章节：见 卷七.md 头部"本卷概览"。
```

### 2. 卷文件头部"本卷概览"

每卷文件开头（文件头之后）加：

```markdown
## 本卷概览

本卷主题：…

| 章节 | 内容概要 |
| --- | --- |
| 六甲日甲子时断 | 甲日甲子时的格局断语与喜忌 |
| … | … |
```

章节概要一句话点出"讲什么、怎么用"，不重复正文。

### 3. 章节细节

正文保持原文；规则性章节（论X/格X）按概念条目模板整理（定义/查法/用法/禁忌），可单独成 `概念名.md` 或并入章节。

## 二、标点补全

已发现无标点段落：卷七补录三篇（子平说辩、论贫贱凶恶、论寿夭，来自中华文库四库本）；卷一补录两篇（论十干名字之义/论十二支名字之义）；卷十一消息赋七（古诗文网）——以及任何扫描发现的其它无标点段落。

方法：按《格式规范》标点规范逐段断句；文件头注明"断句为整理者所加"。

## 三、卷十二赋的深度整理

卷十二含大量赋论（元理赋/真宝赋/金声玉振赋/金鼎神秘赋/络绎赋/金玉赋/心镜五七赋/造微论/人鉴论/元妙论/精微论/惊神论/明津先生骨髓歌/搜髓歌/四言独步/五言独步等）。

要求：
1. 每篇赋：结合八字知识与前卷章节（格局/用神/十神/宫位）逐段理解。
2. 产出"现代易懂的解释/翻译"：每篇一个 `卷十二·<赋名>解.md`，结构=原文（分段）＋白话释（逐段）＋规则条目（该赋提出的规则：定义/用法/禁忌）＋与前面卷的关联（如"此赋论财官，与卷五论正财呼应"）。
3. 规则性内容必须提取成条目，不只是翻译。
4. 所有解释忠于原文，拿不准标"存疑"。
