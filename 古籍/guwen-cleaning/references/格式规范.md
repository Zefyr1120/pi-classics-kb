# 清洗格式规范

> 本文件是清洗作业的标准与模板。subagent 清洗任何古籍前先读 `references/清洗核心规则.md`（总纲）与本文件。

## 〇、组织原则（总纲）——古籍清洗核心规则

**目标形态**：在保证精确、不失原意的前提下，把爬取到的古籍原文组织为**便于 agent 检索、理解和引用**的形式：阅读时**减少 token 开销**，检索时**快速、全面、准确**。

**方法前提（先观察后设计）**：不同古籍爬取到的原始数据，其文本格式、结构、模式各不相同（标题层级、卷/篇/章边界、无标点或半标点段落、歌诀/赋/论、重复/异体/装饰标记等）。清洗前先观察并分析该书自身的模式，再设计最适合它的组织形式；不套固定模板。

**四条核心规则**：

1. **分层导航、渐进式披露**：上层只放导航与摘要，细节留在下层，agent 按需下钻——
   - **书级目录**（`目录.md`）：每卷/篇一段"大致讲了什么内容、有什么信息"（卷级内容概览），并链接到卷/篇文件；**不做冗长的章节逐条清单**——清单属于下层。
   - **卷/篇级说明**（卷文件头部"本卷概览"）：本卷主题一句话 + 章节清单表（章名 | 一句话内容概要）；卷/篇本身无意义时，以内容主题为组织单元。
   - **章节细节**（正文文件/概念条目/诗诀小节）：原文 + 结构化 + 白话解释。
2. **标点补全**：无标点/半标点文本逐段断句，补规范标点（断句原则见第一节）；不改字、不改语序、不增删文字；文件头注明"断句为整理者所加，供参考"。
3. **赋/歌诀/规则性段落深度整理**：结合八字知识与全书前后文深入理解后，给出现代易懂的解释/翻译；其中规则性内容（定义/查法/用法/禁忌）必须整理成条目，不只是翻译（模板见第三节/第四节）。
4. **出处可回引、存疑标注**：断语、翻译、解释均以原文为据，文件头保留底本路径与篇目；拿不准的标"存疑"，不做义理发明。

## 一、标点补全规范

### 适用范围

- 无标点文本：整篇无标点（如 素问王冰注本、玉照定真经、易纬乾凿度 等，用扫描脚本按标点密度定位）。
- 半标点文本：只有句号无逗号（如 五行大义），按规范补逗号等。
- 文件级密度扫描只是粗筛：整文件标点密度正常不代表卷内没有无标点段落（如三命通会卷七整体正常，但补录的子平说辩/论贫贱凶恶/论寿夭三篇整段无标点），需按章节/段落粒度复核、抽查补录来源，并把已知无标点清单登记进专项指南。

### 断句原则

1. 按句意断句：先分句（句号/问号/叹号），再分逗（停顿、并列、分句）。
2. 常见断句信号：
   - 句首发语词（夫、盖、凡、故、是故、然、且、今、若、虽、苟、惟）后通常可顿；
   - 转折/因果/假设连词（而、则、乃、以、于、之、者、也、矣、焉、耳、乎、哉）所在位置决定分句；
   - 对仗/排比处对齐标点（如 春生夏长、秋收冬藏）；
   - 引文用引号（“ ”），引文内标点按原文语义。
3. 不改字、不改语序、不增删文字；原文【】〔〕等注记标记保留。
4. 不确定处宁断勿连（少用逗号多用句号），并在文件头注明"断句为整理者所加，供参考"。

### 标点集

`，` 逗号｜`。` 句号｜`；` 分号｜`：` 冒号｜`？` 问号｜`！` 叹号｜`、` 顿号｜`“”` 引号

## 二、标题结构化规范

1. 文件命名：`NN-标题.md`（NN=两位序号），标题清洗后作文件名（去全角空格、去书名号、去★）。
2. 标题去装饰：
   - 去书名号：《论　　伤　　官》→ `论伤官`（作章节标题）；正文引用书名/篇名仍可保留《》。
   - 去 `★` 等装饰符号（★后的解释性文字并入正文或转列表项）。
   - 去标题内全角空格：`《干　支　体　象》天　干` → `干支体象·天干`。
3. 正文层级：大节用 `##`，子节用 `###`，并列条目用无序列表 `-`；诗诀等成块内容用引用块或独立小节。
4. 每节文件头统一：
   ```markdown
   > 书名：…｜底本：古籍/<领域>/<书名>-全文.md
   > 节序：NN/总数｜说明
   > 清洗日期：YYYY-MM-DD（guwen-cleaning）
   ```
5. 每本书生成 `AGENTS.md`（| 节序 | 标题 | 项目路径 |），并更新所属领域 README。

## 三、概念条目化模板

规则性段落（定义/查法/用法/禁忌）整理为独立 `概念名.md`，与同书其它概念条目格式一致：

```markdown
# 日德

> 出处：渊海子平·论日德｜底本：古籍/子平/渊海子平-全文.md

## 定义
（原文对概念的一句话定义，白话复述一句）

## 查法
（怎么从八字里找这个概念：哪几日/哪个位置/什么条件）

## 用法
（这个概念怎么用：吉凶判断、组合、喜忌）

## 禁忌/注意事项
（原文列的大忌：刑冲破害、空亡、魁罡等）

## 诗诀（对照整理）
（把相关《诗诀》合并整理，按意思分组，每组一句白话说明；原文保留）
```

要求：定义/查法/用法用简洁白话，忠于原文；诗诀不臆改，只整理归类并给出理解。

## 四、诗诀处理原则

1. 诗诀是古人把规则压成韵文，先对照正文理解其含义，再结构化呈现。
2. 同一概念的多首诗诀合并到该概念的"诗诀"小节，按意思分组。
3. 每首/每组诗诀后给一行白话解释（"此诀言……"），拿不准写"存疑"。
4. 诗诀原文保留（删★、补标点），不重写。
