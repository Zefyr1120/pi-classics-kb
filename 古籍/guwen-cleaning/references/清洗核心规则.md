# 古籍清洗核心规则（总纲）

> 本文件是古籍清洗作业的总纲，适用于库内全部古籍（三命通会、渊海子平、五行大义、六壬大全、周易等）。具体书目的差异与落地示例见 `references/格式规范.md` 及各书专项清洗指南（如 `三命通会优化指南.md`、`渊海子平清洗指南.md`）。

## 〇、组织原则（总纲）

> 本条由《三命通会》专项优化需求提炼，是全部古籍清洗工作的总纲。

**目标形态**：把爬取到的古籍原文组织为——在保证精确、不失原意的前提下，便于 agent 检索、理解和引用，阅读时减少 token 开销，检索时快速、全面、准确——的结构化文本。一切结构化作业（拆分、标点、翻译、条目化）都不增删、不改写义理，只改变组织与呈现形式；断语、翻译、解释均以原文为据，拿不准的标“存疑”。

**方法前提（先观察，后设计）**：不同古籍爬取到的原始数据，其文本格式、结构、模式各不相同（标题层级、卷/篇/章/节边界、无标点或半标点段落、歌诀/赋论/赞、装饰与异体标记、正文与注家夹注混排等）。清洗前先观察并记录该书自身的模式（借助 `screen_guji.py` 粗筛 + 抽样精读），再设计最适合它的组织形式，不套固定模板；库内已观察到的典型差异见第二节表格。

**落到组织形式的三条操作规则**（详细规范见第三、四、五节）：

1. **分层导航、渐进式披露**：书级目录（`目录.md`）放“每卷/篇大致讲了什么、有什么关键信息”的摘要，不做冗长的章节逐条清单；卷/篇级文件头部放“本卷概览”（本卷主题一句话 + 章节表：章名｜一句话内容概要），让“本卷有哪些章节、各讲什么”一目了然；细节留在章节层按需下钻。卷/篇本身无意义时，以内容主题为组织单元。
2. **标点补全，不得遗漏**：无标点/半标点段落先扫描定位、逐一断句补规范标点；注意**整文件标点密度正常不等于卷内没有无标点段落**（三命通会卷七整体密度正常，但补录的子平说辩/论贫贱凶恶/论寿夭三篇为整段无标点，文件级扫描会漏报），定位时须按章节/段落粒度复核并抽查补录来源；不改字、不改语序、不增删文字，文件头注明“断句为整理者所加”。
3. **赋/歌诀/规则段落深度整理**：逐篇结合八字知识与全书前后文深入理解，产出“现代易懂的解释/翻译”；其中的规则性内容（定义/查法/用法/禁忌）必须整理成条目，不只做翻译；所有解释忠于原文、标注出处，拿不准标“存疑”。

## 一、目标

把古籍原文从"原始文本"清洗为**便于 agent 检索、理解和引用**的结构化文本：

- **精确不失原意**：一切结构化工作的底线。不增删、不改写义理；标点、翻译、解释均以原文为据，拿不准的标"存疑"。
- **便于检索、理解和引用**：概念可单独定位；断语有出处可回引（文件头保留底本路径）；层与层之间可跳转。
- **减少阅读 token**：上层只放导航与摘要，细节留在下层文件，agent 按需下钻（渐进式披露），不把全文重复堆进索引。
- **快速、全面、准确**：目录提供"这本书讲了什么、各部分有什么信息"的速览；检索时先看概览，再定位细节。

## 二、方法总则：先观察，后设计

不同古籍的原始文本格式、结构、模式各不相同：标题层级、卷/篇/章节边界、无标点或半标点段落、歌诀/赋论/赞论、重复或异体标记、正文与注家夹注混排。**先分析该书自身的模式，再设计最适合它的组织形式，不套固定模板。**

清洗前先做格式观察并记录清单（观察项）：

- 标题层级：卷/篇/章/节如何呈现？标题是否含全角空格、书名号、☆等装饰？
- 章节边界：靠什么切分（标题行、序号"一/二/三"、"第一/一者/二者"、空行）？
- 标点状况：整篇无标点、半标点（只分句不分逗）、还是已带完整标点？
- 文体结构：是否含歌诀/赋论/赞论等韵文成块？原文与注家夹注（如"（万育吾解）"）如何混排？
- 重复与异体：是否有重复段落、异体标记、繁简混排？

库内已观察到的典型模式：

| 古籍（底本来源） | 观察到的格式模式 |
| --- | --- |
| 三命通会（国学3000 逐章整理本） | 简体+现代标点、逐章正文；但卷七补入的子平说辩/论贫贱凶恶等为整段无标点；卷十二为赋论集合（原文+注家夹注） |
| 五行大义（殆知阁） | 无标点断句，保留整理者分段；总目用"第一/一者/二者"嵌套结构 |
| 六壬大全（殆知阁） | 带标点分段；卷目与"入手法""课经"等小节标题混排 |
| 渊海子平 | 标题含全角空格；正文含☆注释与《诗诀》混排 |
| 周易 | 64 卦 + 十翼；卦辞/爻辞/彖/象分层 |

每次清洗先跑 `古籍/tools/screen_guji.py` 或人工抽样，把该书格式清单写进专项指南，再动手；清洗完成后重跑脚本校验。

## 三、分层组织规则（渐进式披露）

三层结构：上层只给导航与摘要，细节留在下层，agent 按需下钻。

### 1. 书级目录（`目录.md`）

- 每卷/篇一段：本卷大致讲了什么内容、有什么关键信息；附卷/篇文件链接。
- **不做冗长的章节逐条清单**——逐条清单属于下一层。
- 卷/篇本身无意义时，以内容主题为组织单元，并在目录中说明主题划分（如三命通会卷十二可按"赋论/规则类/断语类"归纳）。
- 示例（三命通会）：

```markdown
## 卷七 —— [古籍/子平/三命通会/卷七.md](古籍/子平/三命通会/卷七.md)（25 章）

本卷主题：日时断（六甲日甲子时……六戊日癸亥时）+ 子平说辩等命理总论。
关键信息：逐日断语是"日主 × 时柱"的实战索引；子平说辩讲子平法源流与正名。
章节：见 卷七.md 头部"本卷概览"。
```

### 2. 卷/篇级说明（卷文件头部"本卷概览"）

每个卷/篇文件开头（文件头之后）加"本卷概览"：

```markdown
## 本卷概览

本卷主题：……

| 章节 | 内容概要 |
| --- | --- |
| 元理赋 | 论生克制化与清浊贵贱的总纲赋；含"金赖土生，土多金埋"等规则 |
| …… | 一句话点出"讲什么、怎么用"，不重复正文 |
```

章节概要一句话点出"讲了什么、怎么用"，不重复正文。

### 3. 章节细节（正文文件/概念条目/诗诀小节）

- 原文保留（无标点者补充标点），不删不改。
- 规则性章节（论X、查法、格局等）按概念条目模板整理：定义/查法/用法/禁忌/诗诀（模板见 `格式规范.md` 第三节）。
- 歌诀、赋论成块呈现，并附白话理解。
- 每个概念可单独定位、可回引出处。

## 四、标点补全规则

### 适用范围

- 整篇无标点：如三命通会卷七子平说辩/论贫贱凶恶、五行大义（殆知阁版）等。
- 半标点：只有句号没有逗号（如五行大义部分篇章），按规范补逗号等。
- 先用 `screen_guji.py` 按标点密度扫描定位，**不遗漏**任何无标点/半标点段落；文件头注明"断句为整理者所加，供参考"。
- 文件级密度扫描只是粗筛：整文件标点密度正常时，卷内嵌的无标点段落可能漏报（三命通会卷七整体密度正常，但子平说辩/论贫贱凶恶/论寿夭三篇为整段无标点，未出现在粗筛清单中）。定位须分两层——全库粗筛 + 章节/段落级复核，尤其对补录、新增来源逐段检查，并把已知无标点清单登记进专项指南。

### 断句原则

1. 按句意先分句（句号/问号/叹号），再分逗（停顿、并列、分句）。
2. 参考常见信号：发语词（夫、盖、凡、故、是故、然、且、今、若、虽、苟、惟）后通常可顿；转折/因果/假设连词（而、则、乃、以、于、之、者、也、欤、焉、尔、乎、哉）所在位置决定分句；对仗排比处对齐标点。
3. 引文加引号（""），引文内标点按原文语意。
4. 不改字、不改语序、不增删文字；原文【】〈〉（）等注记标记保留。
5. 不确定处宁断勿连（少用逗号、多用句号）。

标点集统一：`，。；：？！、""`。

## 五、赋/歌诀/规则性内容的深度处理规则

对象：赋论、歌诀、赞、口诀等韵文与规则性段落（如三命通会卷十二的元理赋/真宝赋/金声玉振赋/金鼎神秘赋/络绎赋/金玉赋/心镜五七赋/造微论/人鉴论/元妙论/精微论/惊神论/明津先生骨髓歌/搜髓歌/四言独步/五言独步等；渊海子平《诗诀》）。

处理要求：

1. **逐篇深入理解**：结合八字基础知识与本书前文章节（格局、用神、十神、宫位、五行生克）理解每句含义，不孤立处理。
2. **产出"现代易懂的解释/翻译"**：每篇一个独立小节或文件，结构为：
   - 原文（分段）；
   - 白话解释（逐段或逐组）；
   - 规则条目（该篇提出的规则：定义/查法/用法/禁忌）；
   - 与前卷/前文的关联（如"此赋论财官，与卷五论正财呼应"）。
3. **规则性内容必须提取成条目，不能只翻译**——翻译服务于理解，条目服务于检索与引用。
4. 所有解释忠实原文、标注出处；拿不准标"存疑"。

## 六、格式与校验

### 格式

- 文件命名：`NN-标题.md`（NN=两位序号，标题清理后作文件名：去全角空格、去书名号、去☆）。
- 每节文件头统一：书名｜底本、节序、清洗日期（guwen-cleaning）。
- 每本书生成 `AGENTS.md`（节序 | 标题 | 项目路径），并更新所属领域 README。

### 校验清单

- [ ] 无标点/半标点文本已断句，文件头注明"断句为整理者所加"
- [ ] 标题无书名号、☆、全角空格残留
- [ ] 概念条目符合模板（定义/查法/用法/禁忌/诗诀）
- [ ] 赋/歌诀已逐篇处理：原文+白话解释+规则条目+前文关联
- [ ] 编码 UTF-8 无 BOM；繁简统一（干支/讳语环境保留）
- [ ] `screen_guji.py` 复扫通过；AGENTS.md 与领域 README 已更新
- [ ] git 提交信息写清动作与书目

## 七、与专项指南的关系

- 本文件：所有古籍通用的核心规则。
- `格式规范.md`：标点/标题/概念条目/诗诀的具体模板与校验项。
- 各书专项指南（`三命通会优化指南.md`、`渊海子平清洗指南.md` 等）：该书特有结构、待办清单与示例。
- 规则冲突时，专项指南补充本文件，不推翻本文件的原则（精确不失原意、渐进式披露、先观察后设计）。
