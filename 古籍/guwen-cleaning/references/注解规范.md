# 注解规范（章关注解与检索层）

> 适用：古籍库「深度处理」的第二层——在原文/原注**保留不变**的前提下，为便于 Agent 理解与检索，逐章/逐节添加**项目自撰注解**。
> 与清洗的关系：清洗解决"文本形态"（断句/分层/结构化）；**注解解决"理解与检索"**（本章讲什么、何时调用、哪些句子可用）。
> 已有先例：《子平真诠》47 章【章旨】/【疏解】（2026-09-10）。
> 本规范用于：《滴天髓》64 章、《穷通宝鉴》11 节（可扩展到其余书目）。
> 审计背景：古籍处理状态审计（2026-09-15）（滴天髓 5/8、穷通宝鉴 2/8，缺项均为"疏解"）。

## 一、总则

1. **原文不动**：原文、原注一字不改；注解只做**追加**（新增小节），不改动正文行、不删行。
2. **分层标识**：每个注解小节开头声明「本疏解为项目自撰，只疏解原文（与原注），不列命例」。原文层（【原文】/【原注】）与项目注解层严格区分，引用时不得混层。
3. **不义理发明**：注解只写从原文/原注可读出之义；不确定标「存疑」，底本缺陷单独登记并注明"引用时避开"。
4. **检索导向**：注解必须回答两件事——① 本章在讲什么（理解）；② 何时该调用本章（检索）。
5. **项目用法不入古籍**：产品口径（性格映射、报告写法）留在开发协作层；古籍注解只做"本书之内"的理解与检索。
6. **注解留痕**：每文件头部登记「注解：YYYY-MM-DD 项目自撰」；改动可经 git 回溯。
7. **结构骨架统一（供脚本稳定解析）**：全库章节／条目文件共用同一骨架——头部 `>` 元信息块（含「注解：」留痕）→ `## 原文`（底本自带古注时另加 `## 原注`；原文所附命例在 `## 原文` 内）→ `## 章旨` → `## 疏解` → `## 关联章节`（有判定链者必做）。**章节标题一律二级**；三级标题仅用于「疏解」内部的固定子节（见 §三.3）。

## 二、通用结构

### 2.1 章旨
一句话（可加一句展开）：**本章回答什么问题** + **检索词**（供 grep / 语义检索命中）。
句式建议：`本章……。检索词：A、B、C。`

### 2.2 疏解
- 概念与论证脉络（分条）。
- 操作读法（落到盘上怎么看、在判定链的哪一步）。
- 易误读 / 负例（曾经读错的地方）。
- 存疑（底本问题、版本分歧）。

> 内部子节：需要细分的书（《滴天髓》）用 `### ` 固定子节，名称与顺序见 §三.3；其余书可用加粗条目（`- **句解**：…`）。两种写法不影响 `## ` 骨架解析。

### 2.3 关联章节 / 关联条目
写清上下游与互证关系：`《X》承担什么、与本章如何衔接`。**有判定链的书（《子平真诠》《滴天髓》）用 `## 关联章节`，必须写明本章在判定链中的位置**；**查表型书（《穷通宝鉴》）用 `## 关联条目`**，写四类关系——同干相邻月条、共享总论（`00-总论/论X`）、对照本对应章、外书接口。

## 三、《滴天髓》专用规则

结构特征：64 章，每章 = 京图诗句（短，常仅二三句）＋ 刘基原注（可能多条，多引而未发）。章短、链路松（不是线性论证），原注常只指方向不给操作。

**定位（项目口径）**：本书是**原则层／读法钥匙**——解释“为什么这样判”；不承担判据输出（判据以《子平真诠》格局法 ＋ 《穷通宝鉴》调候成器法为准）。

**分层纪律（硬）**：主库只收【原文】京图诗句与【原注】刘基原注；**任铁樵《滴天髓阐微》、徐乐吾《滴天髓征义／补注》等后世注家一律不入主库**（素材存 `_备份-任注删除前-20260910/`，仅供对照，禁止引用）。

**注解目标**：逐章把“诗句—原注—盘上操作”打通，形成可检索、可照做的规范条目；**允许注解篇幅大幅超过原文**（数倍亦可）。

1. **标题化**：诗句加 `## 原文`；原注加 `## 原注`（段落内的【原注】前缀保留）。
2. **章旨以“问题”表述**：源头在哪 / 怎么流 / 卡在哪 / 能不能逆 / 清浊如何 / 气貌如何 / 策略是什么……末尾附「检索词：」。
3. **疏解固定子节（`### `，名称与顺序固定）**：
   - `### 句解`——逐句：诗句 → 直解（贴着原注，**不得引入后世注家语**）→ 盘上对应（哪个字、哪一宫、哪种关系）。
   - `### 判定链位置`——本章属判定链哪一环：立源头 → 定体用 → 画流向 → 找卡点 → 查通关 → 断顺逆 → 辨清浊 → 察隐显 → 落气貌 → 出策略。
   - `### 操作读法`——可照做的判定步骤（看什么、判什么、得出什么）；只写从原文／原注可读出之义。
   - `### 易误读`——常见错读与负例；**把后世注家的过度推演写成“某种读法把此句读成……属过度”**，不引其文、不点名立说。
   - `### 存疑`——底本缺陷（如《源流》末段讹字、《通关》段落重复）、版本分歧、引用禁区（如原注「仁义礼智信」德目不得作人格判词）。
4. **关联章节必须标明判定链位置**（上下游与互证）。
5. **底本存疑单列**：写明“引用时避开何处”。
6. **书级检索表**：全部章注解完成后生成 `滴天髓/检索表.md`（分析问题 → 章号），由 AGENTS.md 链接；AGENTS.md 保持纯导航。
7. **前置校验**：注解前须确认该章原文层与 `滴天髓-原文与刘基原注-全本.md` 一致（非空行序列比对）；底本异文未经校订不得据以立论。

## 四、《穷通宝鉴》专用规则

结构特征：查表型——卷首总论 + 十干各一节；每节按十二月令（或三季分组）列条目，条目以"先X后Y"给出所需之物；另夹赋论片段与命例四柱表。**没有线性论证可循**，检索价值高于推演价值。

**结构（2026-09-15 起，三级）**：

```
穷通宝鉴/
  01-卷首（五行总论）.md
  00-总论/          论木·论土·论金·论水 各一节：AGENTS.md（分节索引）＋ 01-总纲.md ＋ 四季分节.md
  02-甲木/  AGENTS.md（干索引）＋ 01-三春甲木总论.md … 14-十二月甲木.md
  ……
```

1. **条目拆分规则**：
   - 一条原文（含所附命例）一个文件；**合月条目不硬拆**（如"三夏己土"覆盖巳午未、"五六月甲木"覆盖午未）；
   - 标题与正文同行的条目（如"四月甲木退气，丙火司权……"）以标题开新条目；
   - 同一条目的续段（同标题重复出现）并入该条目；正文仅标题行的"分组标题"（如"三夏甲木"）并入下一条目；
   - 源文两处交错重复的同题条目以 `-2` 后缀保留，不合并。
2. **干索引（`NN-干/AGENTS.md`）**：承载【章旨】【疏解】【月令速查】+ 条目清单。
   - **月令速查表**（本层即检索入口）：

     | 月令 | 条目 | 主用神 | 气候轴 | 成器轴 | 关键机制 / 降级 | 文件 |
     |---|---|---|---|---|---|---|

     - **月令**列写地支（寅/卯/…/亥子丑），必要时注节气（如"八月乙木白露后用癸、秋分后喜丙"类反转）；
     - **主用神**照抄原文的"先X后Y"，**不得合并两轴**；
     - **气候轴/成器轴**：按本书内部逻辑拆分（气候轴=修复环境；成器轴=日主成形加工）；同一字可分属不同轴时要注明；
     - **关键机制/降级**：有根/被伤（透而无根、被合被冲）、替代物（"姑用"）、阶梯降级（"科甲→小贵→小富→平常"与"苗槁"类机制描述）；
     - 表中**不得新增断语**，只做原书条目的摘录与归类。
3. **条目文件**：`## 原文`（+命例）→ `## 章旨` → `## 疏解` → `## 关联条目`（与子平真诠同序，末节为关联）。
   - 章旨：本条回答什么问题 + 检索词；
   - 疏解：主用神／两轴／机制降级／判词分层／命例说明／易误读（条目级，可比干级更细）；
   - **关联条目**（2026-09-15 起，148/148 覆盖）：四类——① 同干相邻（月令序：上一条／下一条）；② 共享总论（`00-总论/论X/季节.md`）；③ 对照本对应章（问真徐乐吾评注本；差异见 `_对照-徐乐吾评注本-问真版/_差异清单.md`）；④ 外书接口（《子平真诠》格局章／《滴天髓》气势章）——**外书接口由关键词映射生成，引用前须核**。
4. **判词分层标注**：原书三类文字在索引或条目疏解中标注——① 气候/成器判据（可用）；② 十神格局判语（格局层，本书不作主判）；③ 吉凶/身体/人格判词（使用时剥离，标注"（原文判词）"）。
5. **命例与赋论**：在疏解中说明其性质（"时日月年"四柱表 = 原文所附命例；"勾陈全备润下……" = 另段赋论文体），提示检索时忽略，不作判据来源。
6. **卷首节**重点注解全书总纲（"各致其用"/"过与不及"/"土无常性"），它是所有月令条目的读法钥匙。
7. **书级检索**：`AGENTS.md` 中注明"查表入口 = 日干 × 月令（切节气/上下半月）：书导航 → 干索引（月令速查）→ 条目文件"。
8. **验证要求**：拆分后必须做"全文 ↔ 新结构（卷首 + 全部条目）非空行序列全量比对"，行数完全一致方可交付。
9. **共享总论分节（`00-总论/`，2026-09-15 方案 B）**：跨干共用的「论木／论土／论金／论水」（甲乙／戊己／庚辛／壬癸）独立为 `00-总论/论X/`：
   - 分节粒度＝原书小节（总纲＋春／夏／秋／冬；论土另有「四库专论」一节）；
   - `论X/AGENTS.md` = 索引（章旨＋疏解＋四季索引表：季节｜覆盖月令｜一句话要点｜何时用｜文件），**不搬原文**（避免两处维护）；
   - 分节文件 = 原文（＋自身章旨／疏解）；
   - 各干索引以"共用总论 → `../00-总论/论X/AGENTS.md`"互链（持有方标「共用说明」，使用方标「共用总论」路径）。

## 五、质量校验清单

- [ ] 原文、原注未被改动（`git diff` 只增不改）；
- [ ] 结构骨架统一：头部 `>` 元信息块（含「注解：」留痕）→ `## 原文`（＋`## 原注`／命例）→ `## 章旨` → `## 疏解` →（`## 关联章节`）；章节标题无三级；
- [ ] 注解小节带“项目自撰”声明；
- [ ] 章旨含检索词；关联章节写明判定链位置（穷通宝鉴为「关联条目」，四类关系齐备）；
- [ ] 穷通宝鉴速查表与原文条目一一对应、无新增断语；两轴未合并；
- [ ] 滴天髓：疏解含 §§句解／判定链位置／操作读法／易误读／存疑 五个子节；全文无后世注家语（任铁樵、徐乐吾等）；
- [ ] 存疑／底本缺陷已登记，并写明引用禁区；
- [ ] 文件头已登记注解日期。
