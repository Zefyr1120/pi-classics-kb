# 古籍清洗（guwen-cleaning）

## 目标

把古籍原文从"原始文本"清洗为**便于 agent 检索、理解和引用**的结构化文本：标点规范、标题清晰、概念可单独定位、诗诀与正文互证。清洗不改字、不改语序、不增删内容（标点除外），只在格式与结构层面作业。

### 组织原则（总纲）

清洗的最终形态：**在保证精确、不失原意的前提下，便于 agent 检索、理解和引用；阅读时减少 token 开销，检索时快速、全面、准确。** 完整核心规则见 `references/格式规范.md` 〇节。

- **先观察后设计**：爬取到的不同古籍，原始文本的格式/结构/模式各不相同（标题层级、卷篇章节、无标点/半标点段、歌诀赋论、装饰/异体标记），先分析其自身模式，再设计最适合该书的组织形式；不套固定模板。
- **渐进式披露、分层导航**：书级目录放"每卷（篇）大致讲了什么、有什么信息"，卷（篇）级放"本卷有哪些章节、各讲什么"，细节留在下层按需下钻；卷/篇本身无意义时，以内容主题为组织单元；目录不做冗长清单，而是信息摘要。
- **标点补全**：无标点/半标点文本逐段断句，补规范标点；不改字、不改语序、不增删文字，文件头注明"断句为整理者所加"。
- **赋/歌诀/规则段落深度整理**：结合八字知识与全书前后文理解后，给出现代易懂的解释/翻译；规则性内容提取成条目（定义/查法/用法/禁忌），不只是翻译。
- **精确不失原意、出处可回引**：一切结构化不增删改写义理，标点/翻译/解释均以原文为据，文件头保留底本路径与篇目，拿不准标"存疑"。

## 工作流（五步）

1. **粗筛拆分**：先用脚本按标题/卷/篇正则把大文件拆成 `NN-标题.md`，生成 `AGENTS.md`（项目路径编排）。
2. **标点补全**：对无标点/半标点文本逐段断句，补 `，。；：？！、`；原则见 `references/格式规范.md`。
3. **标题结构化**：去书名号（《》）、去 `★` 等装饰符号、去标题内全角空格；正文小标题用 `##/###` 或无序列表。
4. **概念条目化**：规则性段落（定义、查法、用法、禁忌）整理为独立 `概念名.md`，统一模板见 `references/格式规范.md`；诗诀对照正文理解后并入条目。
5. **校验与提交**：复查断句、确认无残留装饰符、UTF-8 无 BOM、格式与同类书一致；git 提交信息写清动作与书目。

## 工具（scripts）

复用 `古籍\tools\` 下脚本（subagent 直接调用，无需重写）：

- `../tools/screen_guji.py`：粗筛——扫描标点不足（无标点/半标点）、装饰符（★☆◆●）、标题行书名号/全角空格、BOM、繁体残留、未拆分全文，输出问题清单。已内置"底本豁免"：`书名-全文.md` 若有同名拆分目录（如 渊海子平-全文.md -> 渊海子平/），视为底本，不再报装饰符/标题残留（底本保留源文标记，清洗成果在拆分目录）。
- `../tools/split_guji.py`：按标题/卷/篇/章/节正则批量拆分（已内置 15 部书配置）。
- `../tools/parse_zhouyi.py`：周易 64 卦 + 十翼解析（卦辞/彖/大象/爻辞/小象分层）。
- `../tools/split_ziping_chapters.ps1`：滴天髓/子平真诠按章拆分。
- `../tools/convert_simplify.py`：繁转简（保护"乾/徵"语境）。
- `../tools/fetch_*.ps1`、`../tools/fetch_clean_sources.py`：古籍全文抓取（纯文本，禁 PDF）。

新书拆分：在 `../tools/split_guji.py` 的 `CONFIGS` 增加一条配置（书名/源/输出目录/标题正则/命名函数），用 `python split_guji.py --only 书名` 重跑即可。

标点补全前先跑 `../tools/screen_guji.py` 确认待处理文件清单；清洗完成后重跑一遍做校验。

## 边界

- 清洗对象是文本格式，不做义理发明；诗诀整理以正文为准，拿不准的注明"存疑"。
- 版本/来源信息保留在文件头，清洗不覆盖来源 URL 与分层标注。
