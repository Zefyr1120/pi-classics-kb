## 版式差异

- 部分月合章：丁火「八、九月」「十一、十二月」；己土「四五六月」「七八九月」「十十一十二月」；甲木「五、六月」。
- 各干「总论」：甲木总论、庚金总论、壬水总论、戊土「论土」；其余各干无独立总论页（与主库的论木/论土/论金/论水结构不同）。

## 使用纪律

1. 引用须标注来源版本（「问真徐乐吾评注本」），**不得与殆知阁本混引**；
2. 补入主库时按「另采源 + 分层留痕」：只取原文层，注明来源；徐注另存，不并入原文；
3. 本目录为工作性对照资料，待补校完成后可移至开发层归档；**校验用**：主库验证脚本读本目录的「## 原文」层作另采源比对基准（本目录文件不进主库结构）。
