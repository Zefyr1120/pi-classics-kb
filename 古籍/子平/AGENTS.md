# AGENTS.md — 子平命理古籍库导航

> **这份文件是什么**：子平一脉古籍库的**导航索引**，供 Agent 按需定位原文。
> **怎么用**：本文件只给"哪本书、在哪里、讲什么"。需要具体内容时，**再下钻到对应书的 `AGENTS.md` 或章文件**，不要试图从这份索引直接得到答案。
> **上级**：`../AGENTS.md`（古籍总库导航）｜**下级**：各书目录内的 `AGENTS.md` 与章文件

## 三、按任务选书的决策表

| 我要做什么 | 读哪本 | 进哪个文件 |
|---|---|---|
| 排盘后判断整体气势流向 | 滴天髓 | `滴天髓/AGENTS.md` → 相关章 |
| 定用神、判格局成败 | 子平真诠 | `子平真诠/AGENTS.md` → 08-17 章（用神系列） |
| 判断月令取用与顺逆 | 子平真诠 | `08-论用神.md`、`09-论用神成败救应.md` |
| 论财/官/印/食/煞/伤/刃/禄劫各格 | 子平真诠 | `31-47 章`（格局系列） |
| 判断情绪基线、需要什么气候 | 穷通宝鉴 | `AGENTS.md` → 干索引【月令速查】→ 命中条目；材质通例见 `00-总论/论X/` 当季分节 |
| 查某概念的原始定义 | 渊海子平 | `渊海子平/AGENTS.md` → 概念条目或对应节 |
| 查神煞（天乙/桃花/驿马等） | 三命通会、渊海子平 | `三命通会/目录.md`、`渊海子平/AGENTS.md` |
| 查某个断语在古法里怎么说 | 三命通会 | `目录.md` → 对应卷 |
| 对照同一部书的不同版本 | 滴天髓 ↔ 滴天髓辑要 | 两书同章对读 |
| 溯源某个说法的更早原形 | 五行精纪 / 渊海子平 | 按概念名检索 |
